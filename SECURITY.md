# Security

Azad Type can watch and change keyboard input while desktop typing is enabled, so please report security problems privately.

Use **Report a vulnerability** on this repository's [Security tab](https://github.com/liberware/azad-type/security) instead of opening a public issue. Include the version, your Windows version and the steps to reproduce the problem.

This is a volunteer project, so there is no guaranteed response time. Only the latest release is supported.
